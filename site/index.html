Quick Start

Up and running
in five minutes

Follow four steps to transform VS Code into a precision instrument. Every command is ready to copy — just pick your platform.

Select your platform
All terminal commands shown for macOS/Linux
📦
Step 01

Clone or download the repository

Get all the config files onto your machine. Git clone is recommended, but downloading the ZIP works equally well.

bash
$ git clone https://github.com/jamil-codes/Vscode-Setup.git $ cd Vscode-Setup
# Download ZIP: GitHub → Code → Download ZIP # Extract the folder, then open PowerShell inside it: PS> cd Vscode-Setup
🧩
Step 02

Install all 36 extensions at once

One command installs everything via the code CLI. The --force flag ensures updates apply cleanly.

bash
$ cat extensions.txt | xargs -n 1 code --force --install-extension
PS> Get-Content extensions.txt | ForEach-Object { code --force --install-extension $_ }
⚙️
Step 03

Apply settings & keybindings

Your existing config is backed up before anything is replaced — fully reversible. Settings go to the VS Code user profile directory.

bash
# Backup existing settings first $ cp ~/.config/Code/User/settings.json \ ~/.config/Code/User/settings.json.backup 2>/dev/null || true # Apply new settings and keybindings $ cp settings.json ~/.config/Code/User/settings.json $ cp keybindings.json ~/.config/Code/User/keybindings.json
# Backup existing settings first PS> Copy-Item "$env:APPDATA\Code\User\settings.json" ` "$env:APPDATA\Code\User\settings.json.backup" -ErrorAction SilentlyContinue # Apply new settings and keybindings PS> Copy-Item settings.json "$env:APPDATA\Code\User\settings.json" PS> Copy-Item keybindings.json "$env:APPDATA\Code\User\keybindings.json" ` -ErrorAction SilentlyContinue
🎨
Step 04

Install custom CSS & JS

Copies the visual tweak files to your home directory, then update the paths in settings.json. Finish by reloading via the Command Palette.

bash
$ cp custom-vscode.css ~/ $ cp vscode-script.js ~/ # In settings.json, set vscode_custom_css.imports to: # "file:///${userHome}/custom-vscode.css" # "file:///${userHome}/vscode-script.js" # Then: Ctrl+Shift+P → "Reload Custom CSS and JS"
PS> Copy-Item custom-vscode.css "$env:USERPROFILE\" PS> Copy-Item vscode-script.js "$env:USERPROFILE\" # In settings.json, set vscode_custom_css.imports to: # "file:///C:/Users/<YOU>/custom-vscode.css" # "file:///C:/Users/<YOU>/vscode-script.js" # Then: Ctrl+Shift+P → "Reload Custom CSS and JS"
💡
Prerequisites: Install VS Code 1.85+ using the .deb/.rpm package on Linux (not Snap) for full compatibility. Install the Geist Mono font from vercel.com/font for the intended typography. After any VS Code update, re-run the "Reload Custom CSS and JS" command to restore visual tweaks.
